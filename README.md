## TCOAAL Decryptor

**A tool to decrypt [The Coffin of Andy and Leyley](https://store.steampowered.com/app/2378900/The_Coffin_of_Andy_and_Leyley/) (by Nemlei) and restore the original filenames.**
> * **Requires owning the game to work.**

## Installation & Running

This tool is a standalone single binary. You do not need to install .NET or any external libraries.

### Windows
1. Go to the **Releases** page.
2. Download `TcoaalDecryptor-v1.0.0-win-x64.exe`.
3. Just double-click the file to run it.

### Linux / macOS
1. Go to the **Releases** page.
2. Download the correct file for your system (`linux-x64`, `osx-arm64` for M-chips, or `osx-x64` for Intel).
3. Open your terminal in the folder with the downloaded file.
4. Give the file permission to run:
   ```bash
   chmod +x <filename>
   ```
5. Run the tool:
   ```bash
   ./<filename>
   ```
